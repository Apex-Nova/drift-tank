# practice/ — your learning sandbox

Make your own folder here: `practice/<your-name>/`.

Put every small learning script in it, numbered in order, e.g.

```
practice/yourname/01_window.py
practice/yourname/02_move_square.py
practice/yourname/03_rect_collision.py
```

Rules:
- Each script is tiny (aim for under ~40 lines) and runs on its own: `python practice/<name>/01_window.py`
- The game never imports anything from `practice/`
- Messy is fine. This is where you break things on purpose.
- Re-writing a teammate's part to learn it? Do it here, not in their folder.
- Optional: keep `practice/<name>/PROGRESS.md` — a list of topics you've learned.
  The AI tutor reads it to know where you left off.
